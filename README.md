# FIELD//ZERO

**Planetary Terrain Analog Intelligence Platform**

FIELD//ZERO explores how Earth landscapes can serve as terrain analogs for planetary exploration and mission preparation.

The platform compares terrain characteristics across Earth, Mars, and the Moon to identify and evaluate potential analog environments.

## Core Features

- Interactive planetary exploration maps.
- Terrain similarity analysis and candidate rankings.
- Explainable terrain feature comparisons.
- Terrain and climate analysis.
- Mission planning and evidence assessment.

## Study Regions

- **Earth:** Western Desert, Egypt.
- **Mars:** Jezero Crater.
- **Moon:** Taurus–Littrow Valley.

## Technology

- Python
- JavaScript
- HTML & CSS
- Geospatial datasets and visualization tools

## Project Status

Developed as a NASA Space Apps Challenge project.
