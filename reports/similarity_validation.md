## 1. Model definition (summary)

Full derivation and rationale: `metadata/SIMILARITY_METHODOLOGY.md`.

For target body B (Mars Jezero or Moon Taurus-Littrow), scale s (120 m primary, 360 m sensitivity), feature i, and Earth cell value x:

```
Reference model per feature, from the summary JSON only (n, mean m, std d, min lo, max hi):
  negMass = Phi(-m / d)                              Gaussian mass below zero implied by the summary
  model   = lognormal if negMass > 0.15 else beta          (config.distribution = auto; gaussian only if forced)
  lognormal: sigma = sqrt(ln(1+(d/m)^2)), mu = ln(m) - sigma^2/2,        F(x) = Phi((ln x - mu) / sigma)
  beta     : u = (m-lo)/(hi-lo), k = u(1-u)/(d/(hi-lo))^2 - 1, alpha = u*k, beta = (1-u)*k,
             F(x) = I_t(alpha, beta) with t = clip((x-lo)/(hi-lo), 0, 1)      (regularised incomplete beta)
  gaussian : F(x) = Phi((x - m) / d)                                         (forced option only)
Feature score   s_i = 100 * (1 - |2 F_i - 1|) = 200 * min(F_i, 1 - F_i)    (equals 100*erfc(|z|/sqrt 2) for z-score models)
Overall score   S   = sum_i w_i * s_i / sum_i w_i        over features present (weights renormalised per cell)
Contribution    c_i = (w_i / W_available) * s_i           (sum of c_i = S)
Completeness    q   = W_available / W_total               (scored only if q >= 0.5 and >= 2 features)
```

Default weights (configurable, expert-judgement, not fitted): `slope_deg` = 0.3, `roughness_std` = 0.2, `elev_variability_std` = 0.3, `tri` = 0.2.

### Design history and how the gates were set (read this)

1. The first version of the model used a Gaussian reference for every non-skewed feature. Its first full validation run **failed two gated tests**: D2 (the Moon 360 m elevation-variability Spearman agreement with the empirical distribution was 0.760 against a gate of 0.85; Moon mean absolute score error was 19-25 points) and D3 (Moon-model AUC 0.521 and 0.576 against a gate of 0.70).
2. Diagnosis (see the family comparison in section 5): the Gaussian implied by the Moon summary puts about 12% of its mass below zero, which gives very flat Earth cells a score floor near 25 against the Moon reference. That is a real model defect, not a test artefact. The engine was revised to use a bounded Beta distribution on the observed [min, max] for references that are not strongly right-skewed. This uses only summary-JSON values.
3. The D3 threshold of 0.70 was then shown to be **unattainable for a calibrated typicality score**: even a score built from the full empirical reference distribution only reaches the baselines reported in section 5 (about 0.54-0.68). The absolute gate is therefore kept visible as non-gated test D3a (it still fails), and a baseline-relative gate D3b replaced it as the gated test. This replacement was made after seeing the results; it is disclosed here and should be read accordingly.
4. D1 (+/- 15 points) was set after exploratory inspection of the self-calibration numbers; D2 (Spearman >= 0.85) was set before the first run and kept; D4 (auto rule equals lowest-KS family) was added after the family comparison.
5. Because the reference cells were used both to choose the distribution family and to validate it, D1, D2 and D4 are **in-sample**. They show the summary-only model reproduces the full reference data well; they do not show it generalises to a third reference site.

## 8. Assumptions

1. The four features are comparable across bodies **after normalisation to each reference's own distribution**; their native units (degrees, metres) are not compared across planets directly.
2. The Jezero and Taurus-Littrow windows in the processed data are taken as the reference terrains. They are single sites and not representative of "Mars" or "the Moon" in general.
3. Summary statistics (n, mean, std, min, max) are sufficient to define a reference distribution. This is an approximation: lognormal (strongly skewed references) and Beta on [min, max] (others) are moment-matched, not fitted to the full data (calibration in section 5 quantifies the misfit).
4. Feature kernels are identical across bodies and scales (same windows in metres), as recorded in each summary JSON `kernels_m`.
5. Default weights are expert judgement. They are configurable and their influence is measured in section 6.
6. Elevation, aspect, temperature, pressure and all POWER climate variables are excluded (no comparable Mars/Moon measurements exist in the processed data, and absolute elevation is not comparable across planets).

## 9. Limitations

- **Not an environmental analog.** Gravity, atmosphere, thermal regime, regolith/surface material, dust, radiation and illumination are not modelled.
- **Only four terrain-shape metrics, which are collinear.** Spearman correlation between features is 0.75-1.00 in all six terrain tables, so the model effectively measures one ruggedness axis; four features do not make four independent pieces of evidence.
- **Source-resolution differences.** The Moon grid (118 m native) is barely smoothed at 120 m, Mars (20 m) and Earth (about 30 m) are area-averaged, so equal-looking metrics are not equally resolved. The 360 m run reduces but does not remove this.
- **Distribution-shape approximation (revised).** Distributions are moment-matched from summaries (lognormal for the skewed Mars reference, Beta on [min, max] for the Moon reference), not fitted to the full data. Mean self scores are 44.6-50.0 against an ideal of 50, and Earth-cell scores differ from the empirical-CDF score by 2.0-15.1 points on average (section 5), so absolute score values carry roughly that much uncertainty while rank order is reproduced closely. Values beyond the observed reference range score exactly 0 under the Beta model (flagged by `n_outside_ref_range`). The family rule is tuned on two references (the Gaussian mass below zero is 0.12 for the Moon and 0.18-0.22 for Mars; the 0.15 threshold sits between them) and must be re-validated for any new reference site.
- **Low discriminating power.** With a score faithfully built from the full empirical reference distribution, the typicality score separates Mars-site cells from Moon-site cells only with AUC 0.54-0.68. Scores for the two targets should not be read as evidence that a cell is "more Mars-like than Moon-like".
- **Edge cells.** Cells within 1 cell (slope, roughness, TRI) or 2 cells (variability) of the window edge lack kernel values; they are scored on fewer features or not at all, and are never gap-filled.
- **Scale dependence.** Rankings differ between 120 m and 360 m, strongly so for Mars (section 4). A high 120 m score with a divergent 360 m score should be read as scale-specific.
- **Search domain.** Only the one Earth window in the data is evaluated.
- **No ground truth.** No external labelled analog sites were used, so the ranking is validated for internal consistency and calibration, not for scientific correctness of the analog.
- **Spatial autocorrelation.** Neighbouring cells share kernel windows, so adjacent high scores are not independent evidence; candidates are therefore separated by at least 2000 m.
